# التحقق من إصدار سطح المكتب 0.3.0

- 94 اختبارًا للنواة وAPI والتوجيه والإقامة والجلسات وTelegram المحلي وعقود المحدّث والحزم اجتازت في بيئة اختبار نظيفة.
- فتح Qt WebEngine والخادم تلقائيًا من الشيفرة، ثم فتحهما من runtime المعبأ نفسه، نجحا في اختبار offscreen دون تعطيل sandbox المتصفح.
- runtime المعبأ أجاب على GPU عن سؤال عربي بإجابة «باريس»، مع HTTP 200 وfinish_reason=stop، باستخدام Python النظام ومكتبات الحزمة ودون virtualenv القديم.
- بنيت حزمة pacman فعلية، وتمت قراءة metadata وقائمة الاعتماديات من الحزمة. حجم نسخة الاختبار يقارب 15 MiB، دون الأوزان.
- desktop-file-validate وXML الخاص بـ Polkit وفحص صياغة Python وgit diff --check اجتازت.
- يتحقق المحدّث من المستودع والنسخة والمعمارية والـ SHA256 والحد الأعلى للحجم، ويُرفض الملف المحرّف قبل الاستبدال. مساعد التثبيت ينسخ إلى مساحة root ويعيد التحقق من المصدر.

الاختبار المحلي لم يثبت الحزمة فوق نظام المستخدم ولم ينفذ تحديثًا إداريًا حقيقيًا عبر Polkit. منطق التحقق والتنسيق اختُبر دون تغيير حزم النظام. نشر AUR يحتاج حساب AUR وSSH لدى المالك؛ أُعدت ملفات الوصف وخطوات النشر. اختبارات النماذج السابقة للنواة تشمل العربية والإنجليزية والبرمجة والصور والبث والإلغاء؛ اختبار النافذة لا يُعد اختبارًا لكل نموذج أو صوت أو Telegram حي.

إصدارات Actions تبني المحرك من الإصدار المحدد مع GGML_NATIVE=OFF داخل Arch؛ نتيجة job المنشور هي المرجع لبناء الأصول المرفقة بالإصدار.
