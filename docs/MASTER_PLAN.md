## 🛡️ القواعد الهندسية الذهبية

> قواعد من "Build Your Own JARVIS Blueprint" — لا نخالفها أبداً

1. **🌳 وحدة الحالة = ورقة الشجرة**: `src/state.py` لا تستورد أي شيء منا
2. **🌊 بثّ كل شيء**: الجملة تُنطق فور اكتمالها (لا انتظار الرد كاملاً)
3. **🎭 نموذجان**: قوي للمسموع + صغير رخيص للخلفية
4. **🛡️ Fail-Soft**: أداة ميتة = "لم أستطع" مهذبة، صوت ميت = صوت احتياطي
5. **⏱️ Timeout لكل نداء**: لا نداء شبكة/نموذج بدون timeout صريح
6. **📁 لا مجلدات سحابية**: Doctor يحذّر من OneDrive/Dropbox/Drive
7. **📝 اختبار قبول**: كل مهمة لها اختبار واضح — لا تُغلق بدونه
