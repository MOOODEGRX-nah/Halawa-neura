# Neura AI 0.4.0 — مساحة المبرمج والمهارات

- مساحة للمشاريع داخل الواجهة العربية: كود يسارًا ومعاينة يمينًا، وتبديل محفوظ وفاصل قابل للتحريك.
- بث الكود الفعلي أثناء التوليد، مع مسودات واضحة وإلغاء تعاوني واستعادة حالة المهام.
- مشاريع دائمة خارج ملفات التطبيق، وحفظ ذري ومراجعات وحماية من تعارض التعديلات.
- معاينة معزولة لـHTML/CSS/JavaScript المحلي، وعرض كامل بنفس حدود العزل. المشاريع التي تحتاج بناءً أو خادمًا تُحفظ دون تشغيلها تلقائيًا.
- فهرس وملخص للمشروع يجيبان عن التعريف واللغة والغرض دون استدعاء نموذج. التعديل يحتاج المصدر الفعلي للملف.
- مهارات صريحة لفتح المواقع وبحث Brave/YouTube وعرض الملفات وفتح المجلدات والتطبيقات؛ صلاحيات محددة قابلة للإلغاء.
- اختيار GPU بالاسم والذاكرة المقاسة، ومعالج الصورة على الجهاز نفسه، ومعالجة تأخر عدادات الذاكرة بعد تفريغ النموذج.

**التحديث من داخل التطبيق:** افتح «التحديثات» ثم «تنزيل التحديث وتثبيته». تُفحص بصمة SHA256 وحجم الحزمة، ثم يطلب النظام كلمة المرور للتثبيت ويُعاد فتح التطبيق. إذا كانت النافذة القديمة مفتوحة، أغلقها وافتحها مجددًا لتحديث نتيجة الفحص.

**التثبيت أو التحديث من الطرفية على Arch/CachyOS:**

```bash
curl -fsSL https://raw.githubusercontent.com/MOOODEGRX-nah/Halawa-neura/main/packaging/linux/install.sh | bash
```

حزمة AUR مرفقة للتحضير ولم تُسجّل في AUR بعد؛ أمر `paru -S neura-ai-bin` لا يصبح متاحًا بمجرد نشر GitHub. يحتاج الإصدار Linux x86_64 وPython 3.14 واعتماديات Qt/Vulkan المحددة في الحزمة. لا يتضمن أوزان النماذج؛ تبقى أوزانك ومشاريعك وإعداداتك خارج ملفات التطبيق، ولا تُحذف بالتحديث.

التحقق المحلي: 159 اختبارًا، وتوليد فعلي مع Qwen2.5 Coder، ومحادثة وصورة، واختبار Qt للحزمة المعزولة. فحص الصياغة لا يثبت صحة كل سلوك. لا تشغيل Python أو shell أو build مولد تلقائيًا. التذكيرات والخدمات الخلفية مرحلة لاحقة. تفاصيل النتائج والحدود في `docs/QA_v0.4.0_AR.md`.
