# تحقق النسخة المحلية 0.4.0 — 29 أكتوبر 2026، الرياض

هذه نتائج محلية فعلية، وليست ادعاء نشر أو تثبيت. بُنيت حزمة pacman وruntime ثم استُخرجت وشُغلت دون تحديث `/opt/neura-ai/app`.

- نقطة البداية: 101 اختبار regression/security ناجحًا. النتيجة النهائية: **159 passed in 4.43s**. الاختبارات الافتراضية تستعمل backend آمنًا وهميًا، وتعزل عدادات GPU عن الاستدلال الوهمي. شملت المسارات والروابط والحدود والتعافي والمراجعات والتعارضات، وبث UTF-8/fences والإلغاء وإعادة الاتصال، والفهرس والسياق، وAPI origin/auth، والمهارات والصلاحيات.
- الحزمة النهائية: Qwen2.5 Coder 14B ولّد موقعًا من index.html وstyle.css وscript.js، ثم مشروع Python بدالة add. بثت المهمة 210 و66 حدثًا مرتّبًا على التوالي، ووصل file_delta قبل completion. ظلت طلبات health مستجيبة أثناء التوليد. فُحص Python بـAST ولم يُنفذ.
- محادثتا FAST وDAILY واختبار صورة VISION عبر محرك الحزمة الفعلي نجحت على CPU المختار صراحةً. بطاقة 16GB كانت مشغولة بتطبيق للمستخدم؛ لم يُوقف أي تطبيق آخر لتوفير الذاكرة.
- اختيار RX580 المقاسة من الإعدادات، ثم FAST→VISION ومعالج الصورة على الجهاز نفسه، نجح من الحزمة النهائية. كشف الاختبار تأخر عدادات VRAM بعد التفريغ، وأُضيف انتظار محدود حتى ثانيتين مع الاحتفاظ بالقفل. لا تحويل صامت إلى CPU.
- Qt WebEngine 6.12 من ملفات الحزمة النهائية: بدء النافذة، CSS محلي، تفاعل JavaScript، كود يسارًا، تبديل، full-page بنفس capability/sandbox، منع parent/storage/cookies/API/local network/clipboard، عدم وصول تنقل إلى خدمة QA أخرى، عرض Python دون iframe/تشغيل، profile off-the-record، وإغلاق الخادم المملوك: نجحت.
- ملف ELF الخاص بحزمة المراجعة بدأ Qt/Backend وأعاد ready=true وversion=0.4.0، ثم أغلق منفذ خادمه. اختبر بملف XDG منفصل. لم تُثبّت الحزمة.
- فحص المتصفح: التفاعل مع موقع مولّد فعليًا، تعديل وحفظ CSS، تعارض مع مراجعة أحدث دون overwrite، حفظ تفضيل swap بعد reload، معاينة كاملة بنفس URL/sandbox، منع parent/storage/API في fixture أمني، وعرض 600px مع تبويبي Code/Preview. لقطات وأدلة القياس ضمن تسليم outputs.
- تحقق متصل بالحزمة النهائية: أُنشئ مشروع CV من الواجهة مع Qwen Coder الحقيقي على CPU، وشوهدت مسودة جزئية بها 187 حرفًا قبل completion، ثم حُفظت الملفات الثلاثة وعمل زر JavaScript وأظهر «مرحبا». صور أثناء التوليد وبعده منفصلة عن fixtures السابقة.
- المهارات: اختبارات أمان باستخدام fakes، وأربع طلبات فتح حقيقية إلى Brave وKate وDolphin وKCalc. النجاح قبول طلب الفتح فقط؛ لم يُدّع قراءة نتائج البحث أو مشاهدة فيديو.
- قياس السياق: tokenizer المحلي الحقيقي بوضع vocab_only؛ المصدر الكامل 5237–5240 token للويب و1970–1973 لـPython، والملخص 123–126 و99–102. المسار الفعلي للأسئلة الستة وصيانة الملخص لم يستدعيا نموذجًا. عينات فقط، دون ضمان توفير أو سرعة.
