# تقرير الواجهة المبنية على المحادثة — 0.4.2

التاريخ: 29 أكتوبر 2026، الرياض. التنفيذ في المستودع الفعلي، على فرع محلي مستقل. لم تُنشر هذه النسخة أو تُثبّت إداريًا أثناء المهمة.

## ما تغير

- أصبح التنقل الرئيسي: المحادثة، المراقبة، حول. حُذفت عناصر تبويبي المشاريع والمهارات وصفحتهما اليدوية من DOM، ولم تُخفَ الأزرار وحدها.
- أُبقيت مساحة المبرمج كعرض داخلي يُفتح من المحادثة أو مشروع محفوظ. زر المجلد الوحيد قرب الكاتب (عرضه 38 بكسل في الاختبار) يفتح درجًا فوق العرض الحالي؛ لا ينشئ مشروعًا من النص الموجود في الكاتب.
- فتح المشروع النشط نفسه يعيد عرضه دون تحميل ملفات المحرر من جديد، ولا يوقف اشتراك أحداث التوليد. الانتقال إلى المحادثة أو المراقبة أو الدرج يحفظ التعديلات غير المحفوظة في الذاكرة. تغيير المشروع أو الملف نفسه لا يزال يراجع المستخدم عند وجود تعديلات.
- الطلبات «عدل هذا المشروع…» و«عدل مشروع السيرة الذاتية…» و«افتح مشروع السيرة الذاتية» تحل المشروع من الفهرس أو تطلب الاختيار عند الالتباس. تفتح المساحة وتجهز طلب التعديل؛ لا تنشئ مشروعًا أو مهمة توليد ثانية. يختار المستخدم الملف الفعلي ويراجع طلب التعديل قبل توليده.
- بقيت المهارات والمخططات والتحقق والصلاحيات وواجهات API دون حذف. أزيلت نماذج التشغيل اليدوية من الواجهة، وأصبحت حالة المهارات وتفعيلها وتعطيلها والصلاحيات المتذكّرة وإلغاؤها ضمن نافذة «الإعدادات والنماذج» الحالية، في جزء قابل للتمرير. اختيار Brave والملفات والمجلدات بقي فيها أيضًا.
- حفظ تغييرات الأذونات وحدها لا يعيد تشغيل الخلفية؛ يتحقق المنفذ من الإعدادات الحالية عند كل فعل. إلغاء صلاحية متذكّرة يطبق فورًا. تغيير موارد النموذج يحتفظ بمسار إعادة التشغيل السابق ومراجعة المحرر.
- أُصلحت مراجع التنقل والروابط القديمة وأزرار ملف المشروع ومجلده. الروابط القديمة تعود إلى المحادثة. الكود يسارًا والمعاينة يمينًا مع حفظ التبديل، والمعاينة الكاملة تستخدم العزل نفسه.

الملفات الرئيسية: `web/index.html`، `workspace.js`، `workspace.css`، `skills.js`، `chat.js`، وCSS المعبأ؛ `src/core/chat_dispatch.py` لتوجيه مشروع محفوظ، و`src/desktop/app.py` لضوابط الإعدادات؛ اختبارات `test_chat_first.py` وأداة `qa_chat_first_qt.py` ومحاكيها. القائمة الدقيقة في ملف CHANGED_FILES داخل التسليم.

## البيانات والحدود

لا ترحيل أو حذف لبيانات المستخدم أو أوزانه. المشاريع العادية في `~/.local/share/neura-ai/workspace/` وتُفتح من زر المجلد، والإعدادات في `~/.config/neura-ai/settings.json`. بقيت الأوزان في `/opt/neura-ai/models`. المعاينة المحمولة تستخدم ملف `neura-ai-preview` مستقلًا، ولا تنسخ رموز API أو الصلاحيات أو المشاريع.

بقاء التعديلات غير المحفوظة يخص تبديل العروض داخل التطبيق؛ إغلاق التطبيق أو إعادة تشغيل المحرك ليس حفظًا دائمًا للمسودة، ويظل له تحذير المراجعة. تعديل مشروع مختلف أو ملف مختلف قد يطلب مراجعة التغييرات. طلب تعديل عبر المحادثة يفتح المساحة ويجهز الطلب للمراجعة، ولا يختار ملفًا أو ينفّذ تعديلًا تخمينيًا تلقائيًا.

تفسير الأوامر حتمي بعبارات مدعومة مع توضيح الالتباس. المعاينة للمواقع الثابتة؛ لا تشغيل Python أو shell أو تثبيت اعتماديات أو بناء مشروع مولّد. صلاحية الإجراء محددة ولا تمنح تنفيذ أوامر عامة. النسخة المحلية 0.4.2 جاهزة للمراجعة؛ GitHub والتثبيت الموجود لا يتغيران دون إجراء نشر أو ترقية منفصل.
