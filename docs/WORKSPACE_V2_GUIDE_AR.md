# مساحة المبرمج والمهارات — دليل 0.4.0 المحلي

هذه نسخة مراجعة محلية لـLinux x86_64 على بيئة Arch/CachyOS الحالية، وليست إصدار GitHub منشورًا. لا تحمل أوزان النماذج. يُفتح ملف `Neura_AI_Preview` في حزمة المراجعة مباشرة من مدير الملفات؛ يستخدم Python 3.14 وPySide6 وNumPy واعتماديات Vulkan المثبتة على الجهاز، مع اعتماديات backend المرفقة. لا يحتاج المستخدم بدء خوادم. الأرشيف وحده ليس ضمان تشغيل على توزيعات أو إصدارات Python مختلفة.

## الاستخدام

1. افتح **المشاريع**، أدخل اسمًا وطلبًا، ثم **إنشاء المشروع**؛ أو اكتب في المحادثة طلبًا صريحًا مثل «أنشئ موقع سيرة ذاتية». الأسئلة والشروح والأمثلة القصيرة تبقى في المحادثة.
2. تفتح **مساحة المبرمج** فور إنشاء المهمة. يظهر محتوى الملفات الحقيقي تدريجيًا؛ علامة «مسودة» تعني أنه لم يُعتمد بعد. زر **إيقاف التوليد** يطلب إلغاءً تعاونيًا، وتظل حالة الإيقاف معلنة حتى ينتهي العمل الأصلي ويُحرّر قفل النموذج.
3. الكود يسارًا والمعاينة يمينًا رغم RTL. **تبديل الجانبين** والفاصل القابل للسحب أو الأسهم يحفظان التفضيل. عند ضيق النافذة تظهر أزرار الكود والمعاينة.
4. اختر ملفًا محفوظًا، عدّل الكود، واضغط **حفظ** أو Ctrl+S. يبدأ الحفظ من المراجعة والبصمة المقروءتين. إذا تغيرت النسخة، يظهر محتواها الأحدث مع خيار الاحتفاظ بمسودتك للمراجعة أو تحميل النسخة الأحدث؛ لا تُستبدل بصمت. توجد تحذيرات للمغادرة والإغلاق مع تعديل غير محفوظ.
5. **المشاريع** يعيد فتح المشاريع بعد إعادة التشغيل. **تصدير ZIP** يصدر المصدر الآمن والفهرس. **فتح مجلد المشروع** يستخدم المهارة المصرح بها. ترحيل المخرجات القديمة زر صريح ينسخ المشروع ويحافظ على الأصل؛ لا يتم نقل صامت.
6. افتح **ذاكرة المشروع والفحص** لعرض الملخص وسؤال التعريف أو اللغة أو الغرض، أو تحديث الفهرس بعد مراجعة تغيرات خارجية. التعديل بالنموذج يعتمد على الملف المفتوح فعليًا؛ لا يمكنه استبدال ملف موجود لم يدخل سياق المصدر. API يسمح باختيار حتى ثمانية ملفات ذات صلة.

## مكان البيانات وحمايتها

الملفات الطبيعية في `~/.local/share/neura-ai/workspace/<slug>-<id8>/`. لكل مشروع معرّف opaque مستقل عن العنوان؛ تشابه الأسماء لا يصطدم. `catalog.sqlite3` هو المصدر الرسمي للفهرس، و`.neura/project.json` و`summary.md` نسختان مشتقتان. المراجعات وجورنال التعافي داخل `.neura`، وليست ملفات للمعاينة. لا تستخدم هذه الملفات كأوامر للنظام.

حزمة المراجعة تختار `neura-ai-preview` بدل `neura-ai` في XDG: الإعدادات في `~/.config/neura-ai-preview/`، والمشاريع في `~/.local/share/neura-ai-preview/workspace/` والسجل في `~/.local/state/neura-ai-preview/backend.log`. تنسخ إعدادات موارد النموذج فقط عند أول تشغيل؛ لا تنسخ رموز API أو المحادثات أو المشاريع أو صلاحيات الأماكن، ويكون التحقق التلقائي من التحديثات معطلاً. النماذج الحالية يمكن قراءتها من `/opt/neura-ai/models` دون نقلها.

تتحقق عمليات القراءة والحفظ والتصدير من المسارات باستخدام directory file descriptors وO_NOFOLLOW لكل الآباء، مع رفض symlinks وhardlinks والأجهزة وFIFOs. الحد الحالي 48 ملفًا، 300,000 بايت للملف و2,000,000 بايت للمشروع. المخرج المتدفق محدود بمليون بايت. الملفات النهائية ذرية مع snapshots وتعافٍ من المعاملة غير المكتملة؛ فشل التوليد يحفظ آخر مراجعة جيدة. هذا لا يغني عن النسخ الاحتياطي ولا يضمن التعافي من عطل قرص أو تلف كل نسخ SQLite.

## ماذا تعني المعاينة؟

يدعم الإصدار HTML/CSS/JavaScript ثابتًا بروابط محلية نسبية، وصورًا وخطوطًا ضمن manifest الأصول المشار إليها. تُفحص Python بـAST وJSON بالمحلل، وJavaScript بـtree-sitter وCSS بـtinycss2 وفحص البنية. هذه فحوص صياغة ومراجع، وليست برهانًا على صحة السلوك أو تنفيذ المتطلبات.

React/TSX/TypeScript والمشاريع التي تتطلب build أو خادمًا تُحفظ مع حالة معاينة غير مدعومة. لا يُشغّل npm أو pip أو Python أو shell أو تطبيق ناتج. مشاريع Python تعرض الملفات وتعليمات غير منفذة، دون console وهمي.

المعاينة على origin محلي مستقل بقدرة عشوائية 192-bit مرتبطة بلقطة مراجعة وتُلغى بعد ساعتين أو خروج الخادم. لا يوجد خادم مجلد عام. الملفات الخاصة و`.neura` والأصول غير المشار إليها غير متاحة. sandbox يسمح scripts فقط دون same-origin؛ وCSP يمنع fetch والشبكة والخدمات المحلية والنماذج والإطارات والعمال وobjects. الكود لا يحصل على رمز التطبيق أو cookies أو WebChannel أو native bridge. API نفسه يتطلب token ويرفض Origin:null وطلبات cross-site.

Qt يضيف اعتراض الطلبات وسياسة التنقل ورفض النوافذ والصلاحيات. **فتح المعاينة الكاملة** يوسع الإطار بنفس URL والعزل. فتح URL الخام في Brave غير مدعوم ولا يُستخدم لتجاوز العزل. البحث وفتح المواقع بالمهارات خارج هذا الإطار مسار منفصل بطلب صريح.

الاعتماديات الخارجية محظورة وتُعرض أسبابها؛ بعض المواقع لن تكتمل بصريًا دون استبدالها بأصول محلية. تحليل المراجع ساكن ومحدود: الموارد التي لا يمكن استخراج مرجعها الديناميكي لا تُكشف تلقائيًا، وتظل محجوبة حتى لو حاول المشروع الوصول إليها. sandbox لا يضمن حدًا زمنيًا لاستهلاك JavaScript للمعالج؛ صفحة عالقة قد تحتاج إعادة الاتصال أو إغلاق التطبيق. انتظار قراءة حالة المحرر الأصلي محدود، ويطلب مراجعة المستخدم إذا تعذر الحصول عليها.

## الذاكرة والتكلفة

الفهرس يحوي الغرض المطلوب واللغات المستنتجة من الملفات، نقطة الدخول وأدوار الملفات والمراجعات والفحص وقدرة المعاينة وبصمات المصدر. الغرض وصف للطلب وليس إثباتًا أن الموقع نفذه. الملخص لا ينسخ المصدر، ويستبعد أسماء الأسرار ويطمس أنماط credentials الصريحة. هذا تمويه محدود وليس ضمان اكتشاف جميع الأسرار؛ لا تُدخل أسرارًا في الطلب أو المصدر.

أسئلة «ما هو المشروع؟» و«ما لغته؟» و«لماذا أُنشئ؟» تعاد من البيانات مباشرة، بصفر استدعاءات نموذج. أسئلة السلوك والتصحيح تحتاج ملفات فعلية؛ يفحص النظام freshness ويطلب إعادة فهرسة التغير الخارجي. لا توجد ذاكرة دلالية أو تدريب أو RAG.

قيس tokenizer الحقيقي لملف Qwen2.5 Coder بوضع vocab_only لستة أسئلة على عينتي ويب وPython: سياق المصدر الكامل للويب 5237–5240 token، مقابل 123–126 للملخص لو استُخدم؛ Python 1970–1973 مقابل 99–102. الإدخال الفعلي للأسئلة الستة وصيانة الملخص: صفر model tokens لأن المسار حتمي. هذه عينات محددة لا نسبة توفير أو سرعة عامة، وسياق الويب الكامل يتجاوز أصلًا نافذة 4096 الافتراضية؛ لم يُدّع أنه أُرسل بنجاح للاستدلال.

## المهارات الأولى

من **المهارات** يمكن فتح موقع HTTP(S)، أو بحث Brave، أو بحث YouTube بترميز عربي صحيح، أو عرض ملف مختار، أو فتح مجلد، أو تطبيق مثبت، أو قائمة تطبيقات فتحها Neura. لكل مهارة schema ومدخلات وصلاحيات محددة ونتيجة صادقة. نجاح الفتح يعني قبول طلب التشغيل، لا تحميل الموقع ولا قراءة نتائج البحث أو مشاهدة فيديو.

الأفعال الصريحة في الواجهة تمنح نطاقًا لمرة واحدة لمدة 90 ثانية، ويمكن تذكر الفعل المحدد 24 ساعة وإلغاؤه من الصفحة. اختيار الملفات والمجلدات وإلغاؤها من **الإعدادات والنماذج**. الكود يُعرض في محرر نصوص موثوق؛ ملفات التنفيذ وdesktop launchers لا تُسلّم للفتح العام. التطبيقات تُحل من كتالوج desktop موثوق، وGIO يفسر Exec دون shell أو معاملات حرة. الأماكن المختارة ليست صلاحية لتشغيل ما فيها.

السجل محلي محدود بـ100 فعل مع أوصاف مجردة؛ قائمة الأخيرة سجل Neura فقط. لا قراءة لتاريخ Brave الخاص أو كل نشاط KDE. لا تأليف أو تنزيل مهارات Python تلقائيًا، ولا تنفيذ أوامر أو تثبيت برامج أو إرسال رسائل أو عمليات مدمرة. غياب Brave أو جلسة سطح المكتب ينتج خطأ مفهومًا.

## موارد الاستدلال والتوافق

منسق NeuraLoop وResidency واحد للطلبات، وقفل النموذج لا يُحرر أثناء native generation. عامل المشاريع محدود الطابور ويبث أحداثًا مرتبة مخزنة؛ إعادة الاتصال لا تعيد التوليد، والانقطاع عند إعادة التشغيل يُسجل فشلًا صادقًا مع المسودة. المحادثة والطلب البسيط لا يمران بدورة نماذج إجبارية. التخطيط إضافي اختياري.

اختيار GPU يستخدم الوصف المضبوط والذاكرة المقاسة ثم يحل index الحالي، ويضبط projector على الجهاز نفسه. تطابق أسماء بطاقتين يظل ملتبسًا ويتطلب اختيارًا صالحًا؛ لا يوجد ربط PCI UUID في هذا الإصدار. تقدير VRAM احترازي وليس ضمان تخصيص. بعد تفريغ نموذج سابق ينتظر المنسق حتى ثانيتين لتحدث العدادات قبل إعلان نقص ذاكرة عابر؛ لا يوقف تطبيقات أخرى ولا يتحول إلى CPU صامتًا. اختيار CPU صريح.

API القديم متاح للتوافق، والمخرجات القديمة لا تُحوّل تلقائيًا. الإضافات والمسارات الجديدة موثقة في WORKSPACE_V2_API.md. تحديثات التطبيق لا تضع مشاريع المستخدم في `/opt` ولا تمسها.

## ما بعد هذه النسخة

التذكيرات واستكمال فيديو YouTube مرحلة H منفصلة: لم تُنفذ أو تُفعّل خدمة خلفية أو autostart. التشغيل التلقائي للكود المولد، builds، مؤلف المهارات، وقراءة تاريخ المتصفح خارج النطاق. لا نشر GitHub/AUR أو تثبيت إداري ضمن تسليم المراجعة المحلي.
