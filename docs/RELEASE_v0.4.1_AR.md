# Neura AI 0.4.1 — تصحيح إجراءات المحادثة ومساحة المبرمج

- ربط العبارات العربية والمهذبة مثل «هل يمكنك ان تفتح لي موقع youtube» بمهارة الفتح الحقيقية، دون نموذج أو انتقال إلى صفحة المهارات.
- توحيد مسار تنفيذ مهارات المحادثة والأزرار اليدوية، وإظهار أخطاء التوافر والتشغيل، واختيار الهدف الملتبس داخل المحادثة.
- حماية الطلبات من التنفيذ المكرر عند إعادة المحاولة أو استعادة الاتصال؛ الطلب غير المؤكد بعد توقف التطبيق لا يعاد تلقائيًا.
- فتح مساحة المبرمج من طلب الإنشاء في المحادثة مباشرة، واستعادة أحدث ملفات المشروع عند اكتمال التوليد السريع.
- جمع إرفاق الصورة والجلسات المحفوظة ومساحة المبرمج في شريط إجراءات متجاوب بمحاذاة حقل الكتابة.
- عرض فقرات Markdown وقوائمها وتوكيدها وروابطها وكودها؛ HTML الصادر من النموذج نص غير منفذ، والروابط محدودة بـHTTP(S).
- إجابة أسئلة لغة المشروع وغرضه من الفهرس دون استدعاء نموذج، مع الحفاظ على حفظ الملفات والمراجعات والمعاينة المعزولة.

أوزان النماذج وبيانات المستخدم منفصلة عن حزمة التطبيق. لا تشغيل Python أو shell أو بناء مشاريع مولدة تلقائيًا. نجاح فتح الموقع يعني قبول طلب التشغيل، ولا يعني تحميل الصفحة أو قراءتها. هذه نسخة تصحيح محلية إلى أن يُطلب نشرها؛ نتائج التحقق الفعلية تُرفق مع التسليم.
