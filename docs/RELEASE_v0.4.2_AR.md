# Neura AI 0.4.2 — المحادثة مدخل العمل

- إزالة تبويبي المشاريع والمهارات ونماذج الإنشاء والتشغيل اليدوية المنفصلة.
- زر مجلد صغير قرب الكاتب يفتح درج المشاريع المحفوظة؛ تبقى الملفات وواجهات API كما هي.
- إنشاء المشروع من المحادثة يفتح مساحة المبرمج. طلب فتح/تعديل مشروع محفوظ يعيد استخدامه، ويجهز طلب التعديل لمراجعة الملف المناسب قبل توليده.
- العودة للمحادثة والمراقبة ودرج المشاريع لا تمحو التعديلات غير المحفوظة ولا توقف التوليد. إعادة فتح المشروع النشط لا تعيد تحميل المحرر.
- الإبقاء على الكود يسارًا والمعاينة يمينًا، وتبديل الجانبين والمعاينة الكاملة والعرض الضيق.
- حالة المهارات وتفعيلها وتعطيلها وإلغاء الصلاحيات المتذكّرة داخل الإعدادات الحالية. حفظ الأذونات وحدها لا يعيد تشغيل المحرك.
- الروابط القديمة للتبويبين تعود إلى المحادثة، وأزرار عرض ملف المشروع وفتح مجلده تستخدم المهارات نفسها وتعرض نتيجتها.

حزمة محلية للمراجعة إلى أن يُطلب نشرها؛ لا نشر GitHub/AUR أو تثبيت إداري ضمن هذه المهمة. [نتائج الفحص وحدودها](QA_v0.4.2_AR.md).
