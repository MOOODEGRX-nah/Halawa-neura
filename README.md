# 🤖 Neura — مساعدك الذكي الشخصي

مساعد ذكي يعمل **محلياً على جهازك** (بدون إنترنت بعد التحميل الأول)،
مستوحى من Neura في Iron Man. يرشدك، يبحث بأمان، يفتح مواقع موثوقة،
يدير مهامك، يراك عبر الشاشة، ويتحدث معك بالصوت.

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 🧠 ذكاء محلي | نموذج Qwen 2.5 7B يعمل على جهازك (يدعم العربية) |
| 👁️ رؤية الشاشة | يحلل لقطة شاشة ويشرح لك ماذا تفعل (LLaVA) |
| 🎤 صوت | استماع ونطق (اختياري) |
| 🛡️ مرشد آمن | لا ينفذ أوامر خطيرة — يرشدك فقط |
| 🔍 بحث آمن | يفتح مواقع موثوقة فقط + فلترة روابط |
| 🎮 وضع اللعب | يحدد موارده (نواتين + ذاكرة أقل) أثناء اللعب |
| 💾 ذاكرة محلية | SQLite: محادثات، ذكريات، مهام |
| 🐙 GitHub اختياري | نسخ احتياطي وبلاغات |

## 📋 متطلبات التشغيل

- Windows 10/11
- Python 3.10 أو أحدث (مع خيار Add to PATH)
- 16GB RAM (8GB حد أدنى للوضع الأساسي)
- ~10GB مساحة حرة للنماذج
- إنترنت للتحميل الأول فقط

> **ملاحظة لمالكي بطاقات AMD:** البرنامج يعمل افتراضياً على CPU
> (ممتاز مع Ryzen 7). تسريع GPU لبطاقات AMD يتطلب بناء Vulkan
> متقدم — انظر قسم الأسئلة الشائعة.

## 🚀 التثبيت والتشغيل

```bash
# 1) ثبّت الاعتماديات (مرة واحدة)
install.bat

# 2) شغّل البرنامج
run.bat
```

عند أول تشغيل سيسألك عن تحميل نموذج الذكاء (~4.7GB).
يمكنك الرفض والعمل بالوضع الأساسي، والتحميل لاحقاً من الإعدادات.

## 📦 البنية

```
├── src/            ← الكود المصدري
├── models/         ← النماذج (تُحمّل تلقائياً، غير مرفوعة)
├── data/           ← قاعدة البيانات والإعدادات
└── logs/           ← السجلات
```

## 🏗️ بناء ملف EXE (اختياري)

```bash
pip install pyinstaller
python src/build.py
```

> الطريقة الموصى بها للتوزيع هي مجلد `install.bat + run.bat`
> (أكثر استقراراً مع مكتبات الذكاء الاصطناعي).

## 🐙 النشر على GitHub

البرنامج مضبوط مع GitHub Actions: عند دفع وسم `v*` يُنشأ
`Neura-Portable.zip` تلقائياً في Artifacts و Releases
(مثل نظام halawa-hub تماماً).

## ❓ أسئلة شائعة

**هل يعمل بدون إنترنت؟** نعم، بعد تحميل النماذج.
**بطاقة AMD؟** يعمل على CPU افتراضياً وبشكل ممتاز.
**أين بياناتي؟** كلها محلية في مجلد `data/` — لا يُرسل شيء للخارج.
